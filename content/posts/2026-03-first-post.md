This is the first post on the blog.

The site is intentionally small: Markdown for writing, YAML for metadata, and Hugo for turning the content into fast static pages.

## Why a static blog?

A static site keeps the publishing model easy to understand. There is no application server or database to maintain, so the local development workflow can stay focused on writing and reviewing content.

The site can grow later with features such as RSS improvements, search, or public deployment when those needs become clear.
